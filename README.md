# First Node Project

Node.js und Express Serverprojekt fuer grundlegende Backend-Funktionen und Datenerfassung.

## Funktionalitaeten
- Uebersichtlicher Code und strukturierte Aufteilung der Komponenten.
- Einfache Integration und Anpassung an bestehende Systeme.

## Nutzung
Starte den Server mit `npm start` oder `node server.js`.
